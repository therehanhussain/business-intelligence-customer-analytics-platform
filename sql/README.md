# SQL Scripts & Data Modeling

This directory houses all SQL DDL, DML, transformation scripts, and analytical queries.

## Structure (Planned)
- `schema/`: Table definitions, primary/foreign keys, constraints, and index definitions (PostgreSQL).
- `etl/`: Staging table loads, incremental transformations, and validation checks.
- `analytics/`: Business queries, KPI calculations (RFM metrics, customer lifetime value, cohort retention, product performance).
