# Business Intelligence & Dashboarding

This directory contains artifacts, assets, and design specifications for executive BI reporting (Power BI).

## Structure (Planned)
- `specs/`: KPI definitions, wireframes, user stories, and data model mapping.
- `pbix/`: Power BI report template and project files (`.pbix` / `.pbip`).
- `assets/`: Color palettes, background images, and icon assets aligned with retail executive presentation standards.
